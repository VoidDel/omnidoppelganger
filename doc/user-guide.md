## 安装

从 [Releases](https://github.com/VoidDel/omnidoppelganger/releases) 下载对应系统的桌面安装包（同页还提供三平台独立的 `odg-cli` 命令行压缩包及 `SHA256SUMS.txt` 校验文件）：

- **Windows 10 / 11（64 位）**：下载经代码签名的 `.exe`（NSIS 安装向导）或 `.msi` 安装包。Windows 10 若缺少 WebView2 运行时，安装程序会自动引导补装。
- **macOS（Apple Silicon 与 Intel，macOS 12+）**：打开经 Apple Developer ID 签名与公证的 `.dmg`，把 **OmniDoppelganger** 拖进“应用程序”即可直接打开。（若运行的是本地无证书源码自编译的 Ad-hoc 包被系统拦截，可在终端执行一次 `xattr -cr /Applications/OmniDoppelganger.app` 放行。）
- **Linux（64 位）**：
  - Debian / Ubuntu：`sudo apt install ./OmniDoppelganger_*_amd64.deb`
  - Fedora / RHEL：`sudo dnf install ./OmniDoppelganger-*.x86_64.rpm`
  - Arch Linux：`sudo pacman -U ./OmniDoppelganger-*.pkg.tar.zst`
  - 通用包：给 `.AppImage` 加上可执行权限（`chmod +x OmniDoppelganger_*.AppImage`）后直接运行。

## 第一次打开：配置宗门与心法

点左下角齿轮（或在输入框输入 `/settings`）打开 **设置 › 心法**，先配置至少一家模型来源，分身才能回话。支持三类接入方式：

### 1. 云端模型供应商（API 密钥）

内置支持 **Anthropic**、**OpenAI**、**Google Gemini**、**OpenRouter**、**DeepSeek**、**Kimi（月之暗面）**、**GLM（智谱）**，以及任意 **OpenAI 兼容服务** 和 **Anthropic 兼容服务**。

1. 在宗门列表里点开要用的一家，填入 API 密钥并保存（密钥默认存入系统凭据管理器，不写进普通配置文件）。
2. 如需改用中转站、企业网关或国际站地址（如 Kimi 国际站、智谱 `z.ai`），在同一张卡片里修改接口地址即可。
3. 需要同时配置多家同协议服务（例如两个 OpenAI 兼容网关、国内站与国际站并存）时，点右上角 **新增宗门**，各自起名、独立保存密钥与地址。

### 2. 本机免密模型服务

- **Ollama（本机模型）**：默认连接 `http://127.0.0.1:11434/v1`，无需填写密钥；本机启动 `ollama serve` 并拉取模型后即可直接选用。
- **Magpie（本机网关）**：默认连接 `http://127.0.0.1:3425/v1`；未设鉴权时免密直连，设了鉴权时可填密钥或设置 `MAGPIE_API_KEY`。

### 3. 本机编码 CLI 无头流式引擎

若电脑上已经安装并登录了下列命令行编码工具，OmniDoppelganger 会自动从 `PATH` 和常见安装目录探测可执行文件，**无需再填 API 密钥**，直接复用它们的本机登录态与会话续接能力：

- **Antigravity**（`agy`）— 设置页还会自动展示 5 小时与周度订阅剩余额度
- **OpenAI Codex**（`codex`）
- **Claude Code**（`claude`）
- **Cursor**（`cursor-agent`）
- **Grok**（`grok`）
- **OpenCode**（`opencode`）

### 4. 默认分身、`auto` 智能路由与境界

- **默认分身**：在“设置 › 心法 › 默认分身”里选定新化出分身默认使用的宗门、心法（模型）和境界（思考深度）。已化出的分身不受影响，随时可在输入框下方单独切换心法或跨宗门切换。
- **`auto` 智能路由**：把心法设为 `auto` 时，分身会根据当前选择的境界自动调度同一宗门下的模型——在“练气 / 筑基”档位自动选用轻量高速模型以节省延迟与开销，在“金丹 / 元婴 / 化神”档位自动切回主力旗舰模型。
- **五档境界**：`练气`、`筑基`、`金丹`、`元婴`、`化神` 对应模型推理预算从浅到深五档，可在输入框下方按任务难度随时调整。

## 开辟洞府、项目信任与闲谈

- **开辟洞府（项目会话）**：点左侧栏顶部或首页的 **开辟洞府**，选择一个本地项目文件夹。分身接下来的文件读写、代码搜索、Git 操作和终端默认都围绕这个文件夹展开。在侧栏已有的洞府名称旁点 **+**，可在同一文件夹下再化出新的分身。
- **陌生洞府“项目信任”门禁**：当你打开一个尚未信任的仓库，而其中包含项目级指令或扩展（`AGENTS.md`、`CLAUDE.md`、`.odg/skills/`、`.odg/prompts/`）时，顶部会弹出安全提示横幅。在你点击 **信任此洞府**（或输入 `/trust`）之前，分身不会自动加载这些仓库自带的指令和提示词，防止陌生开源仓库夹带恶意提示词注入。信任记录随时可在“设置 › 禁制 › 通行符”里收回。
- **闲谈（无项目对话）**：不想选文件夹、只想随手问问题、查资料、处理几份文档或画张图时，点首页或侧栏的 **闲谈**（或按 `Ctrl/⌘+K` 搜索“闲谈”）。分身会在 `~/.odg/闲谈` 下回应，只保留对话相关的能力，隐藏只对代码仓库有意义的命令。

## 发号施令与上下文引用

- **引用项目文件（`@`）**：在输入框里输入 `@` 紧跟文件名片段，会弹出洞府文件模糊补全菜单（支持键盘 `↑` `↓` 选择、`Tab` 或 `Enter` 补全），让分身精准定位目标文件。在中间代码查看器里框选连续几行代码点 **引用到对话**，还会把文件路径与精确行号范围一并带入输入框。
- **粘贴与拖拽图片**：直接 `Ctrl/⌘+V` 粘贴剪贴板截图，或点回形针 / 拖拽图片进窗口（支持 PNG、JPEG、GIF、WebP，单张不超过 3.7 MB，单次最多 8 张），视觉模型即可看图排查界面问题或还原设计稿。
- **附带文本与 Office / PDF 文档**：点回形针或拖入文件（单次最多 10 个，支持洞府外文件且无需额外审批）：
  - 代码与纯文本（10 MB 以内）：小文件随消息直接送达，大文件由分身按需分段读取。
  - Office 与 PDF（50 MB 以内）：自动提取 `.pdf`（按页）、`.docx`（保留标题/列表/表格结构）、`.xlsx` / `.xlsm` / `.xls` / `.ods`（按工作表提取单元格计算值）、`.pptx`（按幻灯片及演讲者备注）的正文供分身研读。
- **内联运行命令（`!命令`）**：在输入框里以 `!` 开头输入本机命令（例如 `!git status` 或 `!cargo check`）并回车，会在当前洞府直接执行该命令（最长 30 秒），并将标准输出/错误折叠成一张可移除的终端输出卡片附在输入框上方，方便你连同自己的说明一起发给分身排错。输入 `!!` 开头则发送字面上的 `!`。
- **中途传音与收回分身**：分身正在运功时，输入框不会锁死——写完话点 **传音** 会在当前工具步骤结束后顺滑捎给分身，点旁边的闪电按钮则立即插话；点 **收回**（红色停止钮）立即中止当前轮次。

## `/` 斜杠命令与提示词模板

### 内置斜杠命令

在输入框行首输入 `/`（或点输入框下方的 `/` 按钮）打开命令面板，支持中英文别名筛选，`Tab` 补全，`Enter` 执行：

| 命令 | 中文别名示例 | 作用 |
|---|---|---|
| `/new` | `/新分身` `/化出` | 在当前洞府再化出一个新分身 |
| `/aside` | `/旁聊` `/侧聊` | 打开右侧只读“旁聊”面板，不打断主分身 |
| `/fork` | `/分叉` | 将截至目前的对话分叉为一个独立的新分身 |
| `/compact [重点]` | `/凝练` `/摘要` `/压缩` | 将前情浓缩为摘要，可附加保留重点（如 `/compact 保留接口签名与报错栈`） |
| `/usage` | `/用量` `/额度` `/灵石` | 打开灵石与用量面板，查看上下文占用、各模型累计消耗、冷却倒计时与订阅额度 |
| `/export` | `/导出` `/导出会话` | 将当前会话完整导出为 Markdown（`.md`）文件 |
| `/trust` | `/信任` `/授信` | 信任（或收回授信）当前洞府，控制是否加载仓库内的 `AGENTS.md`、`.odg/skills` 与 `.odg/prompts` |
| `/files` | `/文件` `/目录` | 在左侧栏打开当前洞府的文件树管理面板（闲谈会话下隐藏） |
| `/git` | `/版本` `/仓库` | 在左侧栏打开 Git 变更、提交与分支管理面板（闲谈会话下隐藏） |
| `/terminal` | `/终端` `/命令行` | 打开或聚焦右侧交互式本地运行终端（`Ctrl/⌘+J`） |
| `/init` | `/立规矩` `/规矩` | 让分身通读当前项目并生成一份贴合仓库约定的 `AGENTS.md` |
| `/review` | `/审查` | 让分身审查当前工作区尚未提交的 Git 改动 |
| `/model` | `/心法` `/功法` `/模型` | 切换当前分身的心法（模型）或宗门 |
| `/effort` | `/境界` | 切换当前分身的境界（思考深度） |
| `/mode` | `/禁制` | 切换当前分身的禁制（权限模式） |
| `/rename <新名字>` | `/改名` | 修改当前会话标题 |
| `/replay` | `/回溯` | 进入逐步回溯播放器，重演会话每一步 |
| `/skills` · `/mcp` · `/schedule` · `/settings` | `/秘籍` · `/法器` · `/功课` · `/设置` | 打开对应的管理页 |

此外，所有已启用的秘籍也会自动注册成 `/秘籍名 任务说明`，直接指定分身按该秘籍办事。以 `/` 开头但并非已知命令的句子（例如 `/usr/local/bin 找不到`）会照常当作普通消息发送。

### 参数化提示词模板（Prompt Templates）

你可以把高频复用的提示词写成 Markdown 文件，放进：

- **全局模板目录**：`~/.odg/prompts/*.md`（所有会话可用）
- **项目模板目录**：`<洞府>/.odg/prompts/*.md`（信任该洞府后对该项目可用，同名时优先于全局模板）

文件名去掉 `.md` 就是斜杠命令名（例如 `fix-issue.md` 对应 `/fix-issue`）。文件顶部支持可选的 YAML Frontmatter，正文中支持位置参数与默认值占位符：

```markdown
---
description: 按编号排查并修复问题，补齐回归测试
arg-hint: <问题编号> [模块路径]
---
请排查问题 #$1（优先检查目录：${2:-src/}）。
完整附加要求：$ARGUMENTS
额外参数切片示例：${@:2}
```

支持的占位符：`$1`～`$9`（按空格或引号切分的位置参数）、`$ARGUMENTS` 与 `$@`（全部原始参数）、`${@:起始}` 与 `${@:起始:数量}`（参数切片）、`${1:-默认值}`（缺省回退值），以及 `$$`（输出字面上的 `$`）。

## 代码工作台与侧边协同

打开项目洞府后，界面分为左栏、中间主工作区与右栏三块，均可拖拽调宽或折叠：

- **左栏（`Ctrl/⌘+B` 收起/展开）**：顶部可在 **分身 / 文件 / Git** 三个视图间切换：
  - **分身**：按洞府分组列出所有会话，支持按标题、文件夹和聊天内容全文检索，右键会话可改名、分叉、导出 Markdown 或删除。
  - **文件**：浏览洞府目录树，新建文件/文件夹、重命名、删除、一键附入对话；按 `Ctrl/⌘+P` 可唤出快速打开面板（支持 `文件名:行号` 直达对应行）。
  - **Git**：一目了然查看冲突、已暂存、工作区修改和未跟踪文件；点文件在中栏打开语法高亮 Diff 对照；支持单文件或全部暂存 / 取消暂存 / 放弃改动、输入说明提交（`Ctrl/⌘+Enter`）、切换与新建分支、远端 Fetch / Pull / Push 及查看提交历史图谱。
- **中间多标签工作区**：第一个标签固定为 **对话**，从文件树、Git 面板或对话卡片点开的文件以独立标签并排打开，支持代码语法高亮、页内搜索（`Ctrl/⌘+F`）、Markdown 与 SVG 源码/预览一键切换、图片缩放预览、Office/PDF 文本预览，以及拖拽行号或框选代码一键 **引用到对话**。
- **右栏协同面板**：
  - **改动**：汇总当前会话改过的文件及增删行数。
  - **终端（`Ctrl/⌘+J` 或 `` Ctrl+` ``）**：内置跨平台交互式多标签 PTY 本地终端，跟随亮暗主题与面板尺寸缩放；选中终端里的报错文本可一键发给主分身排查，也可随时切回查看分身跑过的命令记录与后台任务。
  - **计划**：实时展示分身拆解的待办步骤与完成进度。
  - **产物**：集中列出分身生成或交付的文档、表格、演示稿、图片等产物。
  - **旁聊（`/aside`）**：主分身正在长耗时运功时，可在右侧开启独立的只读旁聊，自动同步主分身当前目标、计划与最近进展，用来追问细节或查阅代码而完全不打断主分身；得出的结论可点 **转给主分身** 一键捎过去。

## 五种禁制、护法、通行符与结界

### 五种禁制（权限模式）

在输入框下方点击禁制按钮切换，或在输入框内按 `Shift+Tab` 在前四种之间快速轮换：

| 禁制 | 文件读写（洞府内） | 命令执行 | 适用场景 |
|---|---|---|---|
| **步步请示** | 改、建、删、移均需批准 | 全部需批准 | 在陌生或高风险仓库里谨慎核对每一步改动 |
| **府内自便**（默认） | 洞府内普通文件自行修改 | 全部需批准 | 日常编码：代码改动可直接对比或一键撤回，命令由你把关 |
| **先谋后动** | 只读不改 | 需批准 | 先让分身摸清代码并呈交方案卡片（`present_plan`），满意后一键切换禁制动工 |
| **放手施为** | 洞府内普通文件自行修改 | 只读/构建/测试命令自动放行，其余经护法或请本尊定夺 | 让分身自主改代码、跑编译与单测闭环 |
| **全权托付** | 全部自动放行 | 全部自动放行（含洞府外、`.git`、联网、MCP） | 仅限**独立工作树**分身手动开启，开启后输入框呈朱红色警示 |

> 无论处于前四种中的哪一种，凡是触碰**洞府以外的路径**、修改 **`.git/` 目录下的文件**、访问未授权的新网站或调用未授权的 MCP 工具，内置引擎的分身都会先递上朱丝栏奏折等你批准（卡片聚焦时按 `Ctrl/⌘+Enter` 批准，`Ctrl/⌘+Backspace` 驳回）。
>
> **本机 CLI 无头引擎说明**：选用 `agy`、`codex`、`claude`、`cursor-agent`、`grok`、`opencode` 等外部 CLI 时，无头流式模式不弹出逐条审批卡片，五档禁制会映射为对应 CLI 的运行权限——**步步请示**与**先谋后动**均保持只读（禁止改文件与跑命令）；**府内自便**仅放行洞府内文件修改、不自动放行终端命令（Codex 以 `workspace-write` 沙箱运行）；**放手施为**交由该 CLI 的自动/分类器模式执行命令并桥接已启用的 MCP 法器；只有**全权托付**才会跳过该 CLI 的全部权限检查。未获信任的陌生洞府不会向外部 CLI 自动传递 `--trust`。

### 护法与请示限时

- **护法（模型安全审核）**：在“放手施为”模式下，内置规则（`safety.rs`）拿不准的命令会先交给“护法”模型审查（默认开启，可在“设置 › 禁制”里关闭或指定专用小模型）。护法只看你的指令、分身的意图说明和命令本身，不看文件内容与命令输出，以防被文件里的提示词注入带偏；判定无害则放行并注明理由，拿不准仍请本尊定夺。
- **请示限时**：“放手施为”下遇到需人工审批的操作默认等待 30 秒，超时无人处理则自动驳回，由分身另寻他法继续推进并在回报中说明。在“设置 › 禁制”里将时限填为 `0` 则一直等待。

### 通行符与命令结界

- **通行符（长期许可）**：审批命令、网站或 MCP 工具时，可选 **之后都准**（本会话有效）或 **此府永准**（写入 `~/.odg/grants.json`，重启后在该洞府依然有效，随时可在“设置 › 禁制 › 通行符”逐条收回）。带管道、重定向、子 shell 或 `sh` / `python` 等通用解释器的命令为防夹带任意逻辑，每次均需单独审批。
- **结界（命令沙箱，macOS 与 Linux）**：在“设置 › 禁制”里开启结界后，分身执行的命令及其所有子进程只能向当前洞府、系统临时目录以及你显式填入的额外白名单目录写入文件（macOS 基于系统自带 `sandbox-exec`，Linux 基于内核 Landlock 5.13+，无需安装额外软件）。若包管理器因需写全局缓存被结界拦截，分身会说明原因并单独请示“出结界重跑一次”。

## 代码导航与批量检索

- **语言服务代码导航（`code_nav`）**：相比纯文本正则搜索，分身可直接调用 LSP 精准查定义、查引用、查接口实现、看悬停类型签名与文档、看文件符号大纲、按名搜全局符号及获取单文件编译诊断。
  - 支持 **Rust**（`rust-analyzer`）、**TypeScript / JavaScript**、**Python**、**Go**（`gopls`）、**C / C++**（`clangd`）。

- **批量只读检索（`batch_inspect`）**：当分身需要一次性摸清多个模块时，可将多条读文件、搜内容、按名找文件请求合并为单次 `batch_inspect` 批处理调用（界面印章标为“览”），大幅减少多轮往返等待与上下文开销。

### 身外法器（MCP）

点左侧栏底部的 **法器**（或输入 `/mcp`）：

- **内置联网搜索与取网页**：即使不配 MCP，分身也自带 `web_search`（在“设置 › 神通 › 天机阁”配置：支持智谱搜索接口，或无智谱密钥时自动回退到 Anthropic / OpenAI 官方自带搜索）与 `fetch_url`（将网页、在线 PDF、Office 文档转为纯文本读取）。

### 秘籍（Skills）

点左侧栏底部的 **秘籍**（或输入 `/skills`）：

- 内置**十五部**专项秘籍：**提交说明**（`commit-message`）、**审查改动**（`code-review`）、**系统排错**（`debugging`）、**编写测试**（`writing-tests`）、**端到端实测验证**（`e2e-verification`）、**安全重构**（`refactoring`）、**撰写文档**（`writing-docs`）、**界面设计**（`frontend-design`）、**发布说明**（`release-notes`）、**安全审查**（`security-review`）、**画图**（`image`），以及制作 **Word**（`docx`）、**Excel**（`xlsx`）、**PPT**（`pptx`）、**PDF**（`pdf`）文档的四部。打开开关即拷入 `~/.odg/skills/`，你可以按团队习惯自由编辑其中的 `SKILL.md`。
- 平常分身只读取每部秘籍的名称与一句话简介，不挤占上下文；遇到匹配任务或被 `/秘籍名` 点名时才用 `load_skill` 研读全文。
- 支持把团队共享秘籍放在仓库的 `.odg/skills/<名称>/SKILL.md` 下随 Git 提交，也支持让分身通过 `install_skill` 从本地目录或 GitHub 仓库子目录一键安装。

- **产物面板**：分身显式交付（`deliver_files`）或每轮在洞府里新产出的文档、表格、演示稿、PDF、图片、音视频与压缩包，都会汇总在右侧 **产物** 面板，点击即可打开预览或在系统文件管理器中定位。

## 长会话、分叉、回溯、撤销与导出

- **灵石用量与账单估算**：输入框下方的 **灵石** 实时展示当前上下文占用比例、累计输入/输出/缓存命中 Token 明细，并按主流模型公开单价估算本会话的美元开销（本机 CLI 与免密本地模型不计 API 费用）。点开灵石面板可直接调整自动压缩阈值（默认 20 万 Token）。
- **上下文压缩（`/compact`）**：对话达到上限时会自动将前情浓缩为摘要；你也可以随时输入 `/compact`（或带保留重点，如 `/compact 保留数据库迁移约束与未修完的报错`）手动压缩。压缩时会自动原样保留最近刚完成的一整轮对话与文件上下文，避免刚讨论完的细节丢失，且旧消息仍完整保留在界面上供你翻阅。
- **按轮撤回文件改动**：分身每次用工具修改、新建、删除或移动文件前都会先拍下原貌快照（本机 CLI 引擎通过文件读写工具对洞府内普通文件所做的改动同样会自动记录前后快照）。点某轮消息上的撤回按钮，即可将该轮起由文件工具所做的改动一键还原（若某个文件后来又被你自己手动改过，程序会保护你的修改不予覆盖；注意：通过终端命令产生的文件变化不在撤回之列）。
- **会话分叉与试错摘要**：想换一种实现思路时，点任意一轮消息下方的 **从这里分叉**（或标题栏的分叉按钮），即可带着此前全部上下文开启一个新分身；若原分支在那一点之后已经做过若干尝试，新分身还会收到一份简明的“原分支试错摘要”提示条，避免重蹈覆辙。分叉只复制对话记录，不复制磁盘文件。
- **逐步回溯（`/replay`）**：点标题栏的回溯按钮，像播放录像一样按步重演整个会话的对话、工具调用、审批决策，右侧改动、终端、计划、产物四栏同步回到当时的状态，支持单步前后、倍速与拖拽进度。
- **导出 Markdown（`/export`）**：点标题栏导出按钮、侧栏右键菜单的 **导出 Markdown** 或输入 `/export`，即可将会话（含模型信息、Token 统计、对话正文与精简工具轨迹）保存为干净的 `.md` 文档，便于归档、写复盘或分享。
- **独立 Git 工作树（Worktree）**：当洞府是 Git 仓库时，点侧栏洞府名旁的 **分支图标** 化出的分身拥有独立的 Git 工作树（位于 `~/.odg/worktrees/`）与专属 `odg/…` 分支。你可以同时派几个分身并行尝试不同方案而互不干扰；满意后点标题栏的 **并回** 即可将改动提交并合并回主工作区当前分支（若存在合并冲突会自动安全中止并提示冲突文件，绝不弄乱原工作区）。

## 命令行 `odg`

除桌面窗口外，还提供共用同一套 `~/.odg/` 配置、密钥、通行符、MCP 与秘籍的命令行工具 `odg`（可直接从 GitHub Releases 下载三平台独立 `odg-cli` 压缩包，macOS / Linux 也可在桌面端“设置 › 神通”一键软链至 `~/.local/bin/odg`，或源码构建 `cargo build --release -p odg-cli`）：

```bash
# 查看当前 CLI 版本号
odg --version

# 在当前目录跑一次任务（分身回答输出到 stdout，工具过程输出到 stderr）
odg "排查为什么单元测试失败并给出修复补丁"

# 指定其他工作目录与“放手施为”模式
odg -C ../my-service --mode auto "跑一遍测试并修掉编译警告"

# 续接当前目录最近一次会话 / 按会话 ID（或唯一前缀）恢复指定会话
odg -c "顺便把刚改的函数补上文档注释"
odg -r 8f3a1c "继续完成剩下的重构步骤"

# 在隔离的 Git 工作树里启动新会话（不碰当前工作区），或开启“全权托付”无交互执行
odg -w --mode auto "尝试把日志库迁移到 tracing"
odg -w --mode bypass "在隔离工作树中全自动完成重构并跑通全部测试"

# 将 -w 独立工作树会话的改动一键提交并安全合并回原工作区当前分支
odg --land 8f3a1c

# 在脚本或流水线中输出结构化 NDJSON 事件流，或无交互自动批准/拒绝
odg --json --no "只读审查当前分支的安全隐患"

# 不跑模型，直接把某个历史会话导出为 Markdown
odg --export 8f3a1c > session-notes.md
```

在命令行任务里同样可以直接写 `/模板名 参数` 调用 `~/.odg/prompts/` 或项目 `.odg/prompts/` 下的提示词模板。运行 `odg --help` 查看全部参数。

## 数据存放在哪里

所有本机数据统一存放在用户主目录下的 `~/.odg/`（Windows 为 `%USERPROFILE%\.odg`，macOS / Linux 为 `~/.odg`；若设置了环境变量 `ODG_HOME` 则改用该目录）：

| 路径 | 内容 |
|---|---|
| `sessions/<id>/session.v1.jsonl` | 每个分身会话的完整追加式事件日志（对话、工具调用与结果、审批）及同目录下的每轮文件撤销快照 |
| `settings.json` | 宗门、默认心法、禁制、结界、护法、界面语言（`locale`）、文房自动更新（`auto_update_runtime`）、主题等设置 |
| `credentials.json` | 仅在系统凭据管理器不可用或显式指定了 `ODG_HOME` 时才生成，存放密钥 |
| `grants.json` | 按洞府隔离保存的通行符（长期命令授权、项目信任等） |
| `mcp.json` | 已启用的内置与自定义 MCP 法器配置（注意：写入其中的令牌、请求头与环境变量按规范为明文） |
| `schedules.json` | 功课（定时任务）配置 |
| `model-usage.json` | 本地各模型累计 Token 消耗统计与限流/额度冷却截止时间 |
| `models.json` | 各供应商返回的模型上下文窗口大小缓存 |
| `skills/` | 已启用或自建的全局秘籍（`<名称>/SKILL.md`） |
| `prompts/` | 全局参数化提示词模板（`<命令名>.md`） |
| `lsp/` · `runtime/` | 按需下载的独立语言服务可执行文件，以及文房 Python 3.12 与文档库 |
| `worktrees/` | 独立工作树分身的 Git Worktree 目录 |
| `闲谈/` | “闲谈”会话默认读写文件的目录 |
| `pastes/` | 输入框粘贴超长文本生成的本地临时附件（超过 7 天或从草稿移除时自动清理） |
| `mcp-memory.jsonl` | 启用内置 `memory` 本机 MCP 法器时的本地跨会话记忆文件 |
| `app-icon.png` | Windows / Linux 原生系统桌面通知使用的本地应用图标缓存 |
| `tmp/` | 本机 CLI 通信、秘籍拉取与快照中转的私有临时目录（不写入系统公共 `/tmp`） |

API 密钥默认保存在操作系统的安全凭据存储中（Windows 凭据管理器、macOS 钥匙串——官方签名包自动绑定 Developer ID Team ID ACL、Linux Secret Service，条目归在 `OmniDoppelganger` 名下）。在 macOS 与 Linux（Unix）下，`~/.odg/` 根目录及 `sessions/`、`pastes/`、`tmp/` 等敏感子目录统一强制设为 `0700`（仅当前用户可读写），`credentials.json` 与 `mcp.json` 等敏感配置以 `0600` 权限原子写入并拒绝悬空符号链接。卸载应用不会自动删除 `~/.odg/`；如需彻底清除所有本地记录，删除 `~/.odg/` 目录并在系统凭据管理器中移除 `OmniDoppelganger` 相关条目即可。

### 常用环境变量

| 环境变量 | 作用 |
|---|---|
| `ANTHROPIC_API_KEY` · `OPENAI_API_KEY` · `GEMINI_API_KEY` · `GOOGLE_API_KEY` · `OPENROUTER_API_KEY` · `DEEPSEEK_API_KEY` · `MOONSHOT_API_KEY` · `ZHIPUAI_API_KEY` · `MAGPIE_API_KEY` | 对应宗门未在设置页保存密钥时自动读取（Google Gemini 同时支持 `GEMINI_API_KEY` 与 `GOOGLE_API_KEY`） |
| `ANTHROPIC_BASE_URL` | 覆盖默认 Anthropic 官方接口地址 |
| `ODG_AGY_BIN` · `ODG_CODEX_BIN` · `ODG_CLAUDE_BIN` · `ODG_CURSOR_AGENT_BIN` · `ODG_GROK_BIN` · `ODG_OPENCODE_BIN` | 手动指定对应本机编码 CLI 可执行文件的绝对路径 |
| `ODG_PYTHON_MIRROR` · `PIP_INDEX_URL` | 下载“文房” Python 与依赖库时改用自定义镜像源（SHA-256 哈希校验保持不变） |
| `ODG_E2E_WORKSPACE` | 端到端测试用：新建会话时直接使用该工作目录，免弹系统文件夹选择框 |
| `ODG_TEST_DOWNLOADS` | 开发测试用：运行测试时实际联网核验语言服务与运行时的下载流程 |
| `ODG_HOME` | 自定义数据根目录（默认 `~/.odg`）；设置后密钥改存该目录下的 `credentials.json` |
