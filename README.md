# OmniDoppelganger

OmniDoppelganger（`odg`）是一个跑在你自己电脑上的编码 agent 桌面应用：Rust 核心，Tauri 外壳，React 界面。

你选一个文件夹，交代一件事；分身读文件、搜索、改文件、跑命令。读和改这个文件夹里的文件不用问你，每条命令、每次碰文件夹外面的路径、每次改 `.git` 里的文件，都先等你点头。

## 现在能做什么

当前是 v0.1，第一条主线已经打通：

- 闲谈：不想选文件夹时，点侧栏或首页的"闲谈"（也可以按 Ctrl+K 找），分身就在 `~/.odg/闲谈` 里化出，被告知这是一场对话、直接回答，要查的上网查、附上的文件照读，写出的文件放在这个文件夹里。这些分身在侧栏里归在"闲谈"一组；`/init`、`/review` 这类只对项目有意义的命令不出现
- 在一个文件夹里开会话，流式对话，会话保存在本机，重开后原样恢复；会话可以改名、删除，侧栏能按标题、文件夹和说过的话搜索
- 工具：读文件、搜内容、按名找文件和列目录、改文件（带改动对比，可一次改多处，要么全改要么不改）、整文件写入、删除和移动文件、跑命令。读到 PNG、JPEG、GIF、WebP 图片时，交给能看图的模型去看（截图、自己画的图表、设计稿），对话里在这一步下面显示这张图。删除和移动走和改文件一样的审批，"撤回这一轮"也能把删掉的、挪走的放回原处。不会自己结束的命令（开发服务器、监视器）可以放到后台跑，分身随时看它的输出、把它停掉；后台命令在应用关闭时一并结束
- 多家模型供应商：Anthropic、OpenAI、DeepSeek、Kimi（月之暗面）、GLM（智谱），以及任意 OpenAI 兼容服务和 Anthropic 兼容服务。同一种可以加好几个（比如两个中转、同一家的国内站和国际站），各起名字，密钥和地址各存各的。化出的分身先用设置里的那一家和那个模型，之后可以在两轮之间换，也能换到别家：点输入框下方的"心法"，上面一排是宗门（存了密钥的才能选），下面的列表是直接向那一家问来的（问不到时用内置的几个）；设置页里的模型列表也一样。换到别家时，前情照旧带着，只是前面那家的推演过程不带过去。输入框下方的"境界"单独给这个分身换推演深浅，不改设置里的默认
- 五种禁制（权限模式），输入框下方切换，前四种也可以在输入框里按 Shift+Tab 轮换：
  - **步步请示**：改文件也要先批准
  - **府内自便**：文件夹内的改动自行执行，命令要批准（默认）
  - **先谋后动**：不改文件，分身摸清情况后呈上计划，一键换禁制照计划动手
  - **放手施为**：只读、构建、测试类命令自行执行，其余命令仍要批准。是否放行由规则判断（`safety.rs`）：整条命令按 shell 的方式拆开，每一段都得是已知的读取、构建、测试命令，不能写文件、不能用文件夹之外的路径、不能藏着执行别的代码，拿不准就请示。它防的是失手，挡不住存心绕过它的模型
  - **全权托付**：什么都不请示，任何命令、洞府之外、.git、上网、身外法器一概自行放行。只能在独立工作树的分身上、从输入框下方的禁制菜单里打开，打开前弹窗说明并要确认；不能设为新分身的默认，功课也用不了；打开后禁制按钮和输入框标成朱红。Windows 上没有结界，它能删改本尊能动的任何文件
- 护法（模型审核，默认关）：放手施为下，规则不放行的命令先交给另一个模型审。它放行的直接执行，卡片上写明"护法放行"和理由；它不放行或审不了的，照旧请本尊定夺。护法只看得到本尊说过的话、分身动手前说的打算和命令本身，看不到文件内容和命令输出，免得被里面的字带偏。它会看走眼，不能代替结界。全权托付不经护法
- 请示限时：放手施为下，请示默认等 30 秒，没人定夺就自动驳回，分身绕开那一步接着做并在回报里说明；时长在设置里改，填 0 就一直等。别的禁制下一直等
- 请教本尊：拿不准的事（几个方案选哪个、只有本尊说得清的偏好、请求里缺了又查不到的信息），分身用 `ask_user` 一次问清，最多四个问题，对话里弹出一张表单，每个问题一个标签页。每个问题可以是单选、多选或直接写字；有选项的也能在"其他"或"补充"里写自己的话。可以只答一部分，没答的交给分身自定；也可以整张不答，交给分身拿主意。答完分身在同一轮里接着做，表单收成一张问答记录。放手施为和全权托付下照请示的时限等，到时无人作答就由分身自定，并说明选了什么。子分身不能请教本尊，有事回报给派它的分身。命令行 `odg` 在终端里逐题问；没有终端或加了 `--yes`、`--no` 时，交给分身自定
- 审批：命令和文件夹之外的路径要先批准，可以只准一次，也可以之后都准；命令还可以选"此府永准"（这处洞府里永远都准），重启之后也算数，在设置里能逐条撤销。命令的"之后都准"只覆盖同一个前缀（如 `cargo test`），带管道、分号、引号、变量的命令和 `sh`、`python` 这类解释器每次都要批准；改 `.git` 里的文件每次都要批准，因为 Git 的钩子和配置会在你自己运行 git 时生效
- 长会话自动压缩：对话到了上限（默认 20 万 token，设置里可调），分身把前情凝成一段摘要，之后只凭摘要和还没回应的话接着做。输入框下方的"灵石"显示眼下的对话占了多少，点开能看会话累计用量、直接改上限
- 身外法器（MCP）：侧栏的"法器"页里内置了十件常用的，默认都不启用，打开开关就连上：远程的 Context7（查库文档）、DeepWiki（读懂 GitHub 仓库）、Microsoft Learn（微软文档）、Exa（联网搜索，不用 GLM 密钥）、GitHub（要个人访问令牌），本机的 Playwright（操控浏览器）、Chrome DevTools（调试网页）、Sequential Thinking（分步思考）、Memory（跨会话记忆）要 Node.js，Fetch（取网页）要 uv。别的 MCP 服务在同一页下方贴上配置（通用的 `mcpServers` 写法，本机程序或远程网址都行），启用的内置法器也写在这份清单 `~/.odg/mcp.json` 里，GitHub 令牌在其中是明文。也可以叫分身来加：它用 `add_mcp_server` 照服务说明里的配置添进这份清单并马上连接，请示卡片上列出要写入的全部内容（密钥也在其中），每次都先请示，全权托付下也不例外。服务提供的工具交给分身用；这些工具做什么由服务决定，所以无论哪种禁制，每次动用都要先批准，可以选"之后都准"或"这处洞府里永远都准"
- 上网取网页：分身可以用 `fetch_url` 取一个网址的内容来读（文档、issue、原始文件、PDF 数据手册），网页会转成纯文字，PDF、Word、Excel、PPT 取出其中的文字。取不到时（比如 404），分身会看到网站返回的那一页和该怎么办的提示，而不只是一个状态码。请求会发到本机之外，所以每个网站第一次访问都要批准，可以选"之后这个网站都准"。要找网页用下一条的搜索
- 联网搜索：分身可以用 `web_search` 搜网页，拿回标题、网址和摘要，再用 `fetch_url` 读全文。搜索走智谱的搜索接口，用的就是 GLM 的密钥，换哪家模型都能搜。没存 GLM 密钥时，用 Anthropic 或 OpenAI 心法的分身改由那一家自带的搜索来搜：另发一次模型请求，让它用自家的搜索工具搜完，把找到的网页和引文整理成同样的结果列表，这次请求花的灵石也记在账上；用别家心法的分身仍然搜不了。每次搜索前要批准，可以选"之后都准"。设置里能换搜索引擎
- 秘籍：专项的做事说明，平时不占上下文。侧栏的"秘籍"页里内置了十四部，默认都不收入，打开开关才写进 `~/.odg/skills/`：提交说明、审查改动、系统排错、编写测试、安全重构、撰写文档、界面设计、发布说明、安全审查、画图，以及做 Word、Excel、PPT、PDF 的四部；收入后可以照自己的习惯改，改过的关掉前会先问。同一页列出自己的秘籍，可以删掉。每部秘籍是一个文件夹加一份 `SKILL.md`，放在 `~/.odg/skills/` 对所有会话生效，放在项目的 `.odg/skills/` 只对这个项目生效。分身只看得到名字和一句描述，任务对得上时才用 `load_skill` 读全文。也可以叫分身来装：它用 `install_skill` 从本机文件夹或 Git 仓库（GitHub 上指向某个子文件夹的网址也行）装进上面两处之一，每次都先请示，全权托付下也不例外；装好的当场能读，下一轮起列在清单里。分身自己写新秘籍，就照这个格式写进这两处之一
- 待办清单：事情分好几步时，分身列出每一步、做完一步勾一步，右侧"计划"一栏随时能看
- 子分身：事情能拆成互不相干的几块时，分身可以用 `delegate` 一次派出最多八个子分身，各办一块、同时进行，办完把回报交回来。每个子分身是一个独立的会话，沿用主分身当时的禁制和已经准过的事，自己要请示的事在它自己的页面上请示；侧栏里列在主分身下面，对话里那张"派出子分身"的卡片能看到各自的状态并点进去。子分身不知道主分身聊过什么，也不能再派子分身。它们共用同一个洞府，靠任务分工避开同一个文件；主分身的撤销不管子分身改的文件，要撤到子分身自己的页面上撤
- 独立工作树：洞府是 Git 仓库时，侧栏洞府名旁多一个分支图标，点它化出的分身有自己的一份工作树（Git worktree，放在 `~/.odg/worktrees/`）和一条 `odg/…` 分支，从洞府当前的提交起步。它改它的，不碰洞府里的文件，所以几个分身可以同时在一个项目上干活。干完点标题栏的"并回"：把它工作树里的改动提交，合并进洞府当前检出的分支；合并有冲突就原样撤回并告诉你是哪些文件，洞府里什么都不变。洞府里还没提交的改动不会带进工作树。删除这样的分身会连工作树一起删，没提交的改动就没了，提交过但没并回的留在那条分支上
- 功课（定时任务）：侧栏底部的"功课"里，给分身定下到点自己去办的事：每天或每周几天的某个时刻、每隔一阵、或只办一次。到了时辰，程序自行在指定的洞府里化出一个分身，把交办的话传给它，办完的回报留在那个分身里，本尊回来再看；侧栏里它带一个"功课"的标记。每门功课自己选禁制，也可以让每回的分身用独立工作树。到时辰本尊多半不在，所以分身被告知不要停下来发问；要请示的事仍然会候旨，等本尊回来定夺。只在程序开着的时候看时辰：关着时错过的，下次打开补办一回，错过几回都只补一回。上一回化出的分身还没办完，这一回就跳过。功课存在 `~/.odg/schedules.json`
- 分叉：想从对话的某一处换条路走，不必推倒重来。每句话下面的"从这里分叉"另起一个分身，带着这句话之前的全部对话，这句话放回输入框，改了再传；标题栏的分叉按钮则带上到现在为止的全部对话。分叉是一个独立的会话，原来的分身不受影响，侧栏里带"分叉"标记，标题栏能点回它的出处。只分对话，不分文件：两边用的是同一处洞府，文件还是现在的样子，想让文件也回到那时，先在原来的分身里撤回那一轮起的改动。带过来的那几轮改动，要撤回得回原来的分身去撤。子分身的会话不能分叉
- 回溯：标题栏的回溯按钮把页面退回到这个分身刚开始的时候，再一步步放出来：每一步是一句话、一次工具调用的结果、一次请示或定夺。右边的改动、终端、计划、产物四栏跟着显示当时的样子。可以暂停、单步前后走、拖进度、换快慢。回溯只是看记录，不改任何东西，退出后输入框里原来打的字还在
- 结界（命令沙箱，Linux 和 macOS）：设置里布下结界后，分身运行的命令连同它启动的一切（构建脚本、测试、子进程）只能往洞府、系统临时目录和你另外填的目录里写，改不了别处的文件。Linux 用内核的 Landlock（5.13 起），macOS 用系统自带的 `sandbox-exec`，都不用另装东西。只管写入：读文件和联网不受限；Linux 上改权限、属主、时间戳这几样 Landlock 管不到。禁制照旧，该请示的命令仍然请示。命令因为写不进去而失败时，分身会被告知原因，可以请示出结界重跑一次，出结界每次都要本尊点头。默认关着，因为有些命令要往洞府外写（比如包管理器的缓存）。Windows 上还没有
- 项目里的规矩：洞府根目录有 `AGENTS.md`（没有就看 `CLAUDE.md`）的话，分身每轮开始时读它，照里面的规矩办事；文件改了，下一轮生效
- 撤销：分身每次改文件前先存下原样，可以撤回某一轮起的全部改动。分身改过之后又被别人动过的文件不会被盖掉。只管改文件工具的改动，命令改的文件撤不了
- 图片：把截图粘贴进输入框，或点回形针选文件、把文件拖进窗口，分身就能看图说话（PNG、JPEG、GIF、WebP，每张不超过 3.7 MB，一次最多 8 张）。心法得认图才行：Claude、OpenAI、`deepseek-flash`、`kimi-k3.1-pro`、`kimi-k3`、`glm-5.3-flash` 认图；`glm-5.3` 和 `deepseek-v4-pro` 只认字，给它附图时会说明附不了
- 文件：点回形针选文件，或把文件拖进窗口，就附在这句话上（一次最多 10 个）。文件不会被复制，分身读的就是原处那份，而且读它不用请示，哪怕它在洞府之外。100 KB 以内的文本文件，内容随这句话一起发给心法；更大的（到 10 MB）只告诉分身路径，由它分段去读。文档（到 50 MB）取出其中的文字：PDF 按页取；Word（.docx）按段落取，标题、列表、表格保留标记；Excel（.xlsx、.xlsm、.xls、.ods）逐个工作表、逐行取单元格的值（公式算好的结果，不是公式本身）；PPT（.pptx）按放映顺序逐张取，连同演讲者备注。文字不多就随这句话发送，多了由分身用 `read_file` 分段去读。图、图表、排版和扫描件里的字取不出来，扫描件附不了，可以截图附上；老版本的 .doc、.ppt 也附不了，用 Office 另存为 .docx、.pptx 就行。压缩包这类文件附不了。分身在洞府里用 `read_file` 读这些文档也是同样取文字。
- 文房（文档运行环境）：做 Word、Excel、PPT、PDF 和画图的秘籍用的一套 Python 3.12 和 python-docx、openpyxl、XlsxWriter、python-pptx、reportlab、pypdf、pandas、Pillow、matplotlib、qrcode、resvg。安装包里不带，第一次要用时分身会请示（工具 `document_runtime`），也可以在设置的"神通"里装或移除；约下载 90 MB，装在 `~/.odg/runtime`，不动系统里的 Python。以后的版本加了库或换了库的版本，程序启动时（或分身要用时）自动补装缺的那几个，不请示，也不重新下载 Python；只有 Python 本身换了版本才整套重装。Python 按 python-build-standalone 发布的校验码、各个库按 `crates/odg-core/runtime/requirements.txt` 里的校验码核对，对不上就不装；下载慢时可以用 `ODG_PYTHON_MIRROR` 换 Python 的下载地址、用 pip 自己的 `PIP_INDEX_URL` 换库的源，校验照旧。电脑上装了 LibreOffice 的话，分身做完会用它转 PDF、算一遍公式来核对。脚本做出的文件，分身用 `deliver_files` 交给你，在对话里能直接打开或在文件夹中显示。分身没交付的也不会丢：每一轮结束时，程序在洞府里找出这一轮新出现或改过的文档、表格、演示、PDF、图片、音视频和压缩包（不看 `.gitignore` 忽略的和隐藏的文件夹），列在这一轮末尾，也能打开。右边侧栏的"产物"页把交付的和找到的都列在一起，最新的在前
- 画图：分身照"画图"秘籍，能用代码画的都用代码画。流程图、架构图、示意图、图标、海报和卡片写成 SVG，要 PNG 时用 resvg 转；数据图表用 matplotlib；二维码用 qrcode；拼图、加字、改尺寸用 Pillow。中文字体用电脑上已有的。画好的 SVG 和 PNG 在对话里直接显示，也列进"产物"页
- 丹青（生成图片）：照片、写实渲染、插画这类代码画不出来的，分身用 `generate_image` 请图像模型作画，存进洞府（默认 `images/` 下），画好就显示在对话里，也列进"产物"页。画师用的是宗门的密钥和接口地址：有 OpenAI 的密钥就能请 GPT Image 2，有 GLM（智谱）的密钥就能请 GLM-Image、CogView-4、CogView-3 Flash；在设置的"神通"里选哪家，不选就请有密钥的第一家，两家都没有密钥时分身不会被给这个工具。每张都先请示（可以"之后作画都准"）；先谋后动的禁制下不画；已有的文件不会被盖掉
- `/` 命令：在输入框行首打 `/`，或点输入框下方的 `/` 按钮，唤出命令：`/new` 在这处洞府再化出一个分身、`/fork` 分叉、`/compact` 凝成摘要、`/model` 换心法、`/effort` 换境界、`/mode` 换禁制、`/rename` 改名、`/replay` 回溯、`/init` 让分身读懂项目写一份 AGENTS.md、`/review` 让分身审查还没提交的改动、`/mcp` `/schedule` `/settings` 打开对应的页。每部秘籍也是一条命令，`/秘籍名 要办的事` 就是让分身按这部秘籍办。边打边筛，中文别名也认（`/摘要` 找得到 `/compact`）；↑↓ 选，Tab 补全，回车执行，Esc 收起。`/` 后面不是命令的（比如 `/usr/bin 不见了`）照常作为一句话发出去
- 分身干活时可以中途传音，不打断它当前这一步；也可以随时收回
- 分身回话里的代码按语言上色，每段代码都能一键复制；会话标题旁显示洞府里检出的 Git 分支
- 亮暗两套主题

还不能做的事，以及接下来的顺序，见[路线图](doc/ROADMAP.md)。其中最要紧的两条：真实接口只有 GLM 用密钥实测过，其余几家只用模拟的模型服务跑通；还没有安装包。

## 界面风格

风格叫"符箓"，材质只表达一件事：谁做了什么。

- 白纸是本尊的法旨，下面垫着一角黄符，表示分身已经接令。
- 黄符是分身的手笔，每张符开头盖一枚朱砂印，一个字说明是哪类动作：读、搜、改、建、行。
- 朱丝栏的奏折是候本尊定夺的事，朱砂只在这里和印上出现。
- 青玉色是传令，朱砂色是批准，两种动作不共用一种颜色。

文字分两种手笔。标题、印章、黄符上的字是“写上去的”，用[霞鹜文楷 轻便版](https://github.com/lxgw/LxgwWenKai-Lite)（LXGW WenKai Lite，SIL OFL 1.1 许可）；对话、标签和控件上的字是“读的”，用系统自带的黑体（苹方、微软雅黑、思源黑体），小字号下清楚，西文和数字也用它自带的；代码用 Atkinson Hyperlegible Mono。文楷和 Atkinson Mono 随应用打包；黑体用系统的，不增加体积。

## 几条设计约定

- **日志是唯一事实来源。** 每个会话是一个只追加的文件 `~/.odg/sessions/<id>/session.v1.jsonl`。发给模型的每个请求都只从日志推导，界面也只从日志折叠出来，所以重开会话看到的和之前完全一样。
- **压缩也是一条事件。** 对话太长时，摘要作为 `context/compacted` 事件追加进日志，之后的请求从它开始推导；它之前的内容留在日志里，界面照常显示，只是不再发给模型。压缩只发生在两步之间，不会卡在工具调用中间。
- **历史只追加，不改写。** 模型返回的内容块（包括思考块）原样保存、原样回放。DeepSeek、Kimi、GLM 的 `reasoning_content` 和 OpenAI 的加密推理项也一样，后续请求原样带回。
- **换模型、换供应商都是一条事件。** 会话头记下化出时的供应商和模型，之后每次换是一条 `model/changed` 事件，换到别家时带上 `provider`，之后的请求发给新的那一家。同一家之内，历史原样带过去，不删思考内容，新模型读不了的部分由供应商自己略过。换到别家时，从日志推导请求的那一步把别家答的内容换成各家都认的形式：只留文字和工具调用，去掉思考块、加密推理这类别家验不了的东西，工具调用的 id 只留各家都允许的字符，对应的结果跟着改；回到原来那家，它自己答的仍原样发送。只能在两轮之间换。境界（推演深浅）单独换时是一条 `effort/changed` 事件，没换过的分身跟着设置里的默认。
- **每个工具调用都有结果。** 无论一轮是正常结束、被收回、出错还是应用崩溃，日志里不会留下没有结果的工具调用。
- **模型可见的新输入都对应一种会话事件。** 加工具时同时定好审批规则、界面卡片和测试。

## 环境变量

| 变量 | 作用 |
|---|---|
| `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`DEEPSEEK_API_KEY`、`MOONSHOT_API_KEY`、`ZHIPUAI_API_KEY` | 对应供应商没有在设置里保存密钥时使用 |
| `ANTHROPIC_BASE_URL` | 把 Anthropic 请求发到自己的网关；此时不发送只有官方接口支持的字段。其他供应商的地址在设置里改 |
| `ODG_E2E_WORKSPACE` | 端到端测试用：化出分身时直接用这个文件夹，不弹系统的选文件夹对话框 |
| `ODG_HOME` | 会话和设置的存放目录，默认 `~/.odg`。设了它，密钥就存在这个目录自己的 `credentials.json` 里，不碰系统凭据管理器 |

设置里保存的密钥存进系统的凭据管理器：Windows 凭据管理器、macOS 钥匙串、Linux 的 Secret Service，条目归在 `OmniDoppelganger` 名下。早先存在 `~/.odg/credentials.json` 里的密钥，启动时会自动搬过去并从文件里删掉。凭据管理器用不了时（比如 Linux 上没有运行 Secret Service），密钥才留在这个明文文件里，设置页会注明。

## 命令行

不开窗口也能跑一次任务：

```sh
cargo run -p odg-cli -- "给 README 补一节安装说明"      # 开发时
odg -C ../other-project --mode auto "跑一遍测试，修掉失败的"  # 装好之后
```

它和桌面应用用的是同一个分身、同一个家目录：设置、密钥、通行符（长期许可）、MCP 服务、秘籍都通用，跑出来的会话之后在桌面应用里也看得到。分身说的话走标准输出，它做的事和要请示的事走标准错误，所以可以直接把结果接进管道。要请示时，在终端里会问你；没有终端（比如在脚本里）默认一律驳回，加 `--yes` 一律批准。`odg --help` 列出全部选项。

## 测试

```sh
cargo test -p odg-core -p odg-cli
pnpm test
```

核心库的测试不需要 API 密钥：模型由脚本化的替身扮演，工具在临时目录里真实执行。界面的测试覆盖从会话日志折叠出界面的那部分（`src/lib/fold.ts`）。

端到端测试驱动真实的应用窗口，模型由一个按脚本回放的本地服务扮演（只支持 Windows，靠 WebView2 的调试端口）：

```sh
pnpm e2e --build   # 先把应用构建到 target/e2e，再跑
pnpm e2e           # 用上次的构建直接跑
```

它走一遍完整的一轮：化出分身、传令、分身建文件、命令等审批、批准、收尾，再撤回改动，然后核对界面、磁盘上的文件、发给模型的请求和会话日志。应用跑在临时目录里的家目录、工作文件夹和浏览器数据上，不碰你的会话和密钥，也不影响已经开着的应用。脚本在 `e2e/`：`mock-llm.mjs` 是模拟的模型服务，`cdp.mjs` 是调试端口的客户端，`run.mjs` 是测试本身。

每次推送到 `main` 和每个合并请求都会自动跑一遍（`.github/workflows/ci.yml`）：核心库和命令行在 Windows、Linux、macOS 上各跑静态检查和测试，前端和桌面外壳在 Windows 上跑测试、构建和静态检查。只改文档不触发。

## Logo 和图标

logo 是一个沿 S 线分成两半的圆，盖在一方朱砂印上：白的一半是本尊，金的一半是分身，两半微微拉开，合则为一，分则为二。界面里不带印底的那个小标记是同一个图形，用来表示状态：空闲时两半合拢，运功时分身那半来回游离，候旨时它变成朱砂色并停在外面。

应用图标的源文件是 `app-icon.svg`。改了它之后重新生成各个尺寸：

```sh
pnpm tauri icon app-icon.svg
```

这条命令还会生成 `src-tauri/icons/android` 和 `ios` 两个目录，桌面应用用不到，可以删掉。构建脚本只在 `src-tauri/tauri.conf.json` 变化时才重新嵌入图标，所以生成后要改动或 `touch` 一下这个文件再构建。
